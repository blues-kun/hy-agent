## 1. 评估依据与口径

本次只依据以下冻结材料进行桌面预评估：

- `eval/data/evidence_pool_manifest.json`：12 篇综述的元数据、参考文献数量、全文落盘状态、路径和 SHA-256；
- `docs/verification_report.md`：主题覆盖、数据源限制和评测方法学核验结果。

“纳入”只表示该综述适合作为**检索入口、主题框架或二级证据候选**，不表示：

- 综述中的每句话已经被核验；
- 其全部参考文献都与 β 细胞线粒体直接相关；
- 综述可以替代原始干预实验；
- 其参考文献池已经成为金标。

逐条机器可读记录见 `review_pool_assessment.jsonl`。

## 4. 推荐的分层使用方式

### A. 高优先级全文锚点组

REVPOOL-003/004/005/007/008/010/012 已有本地 XML 和 SHA-256。可先用于：

1. 生成 `prefix/exact/postfix` 文本锚点；
2. 抽样验证锚点能否在冻结 XML 中唯一重定位；
3. 标记综述自己的判断与其转述的原始研究；
4. 再回溯原始论文，不把综述文本直接提升为一手实验金标。

### B. 无本地全文的定向种子组

REVPOOL-001/002/006/009/011 可继续用于元数据检索和参考文献召回，但在取得合法全文或
原始研究以前，不应生成声称“已核验原文”的 EvidenceSpan。

### C. 主题互补

- 动力学：REVPOOL-002、007；
- mitophagy：REVPOOL-006、011；
- Ca²⁺：REVPOOL-004、005、010；
- 代谢偶联：REVPOOL-003、004、008；
- redox与膜电位：REVPOOL-008、009、010；
- 糖脂毒性：REVPOOL-009、012；
- mtDNA转录：REVPOOL-001、003。

这种互补适合构建检索覆盖，不代表各综述的观点彼此独立。多个综述可能引用同一篇
原始论文，因此“被两篇综述引用”不能直接当作两份独立实验证据。

## 5. 人工审核问题

两位专家应在不知道上述 AI 决定的情况下，分别回答：

1. 该综述是否与 β 细胞线粒体证据综述场景相关？
2. 它适合用于检索种子、背景综述、冲突发现，还是不纳入？
3. 主题范围和排除范围是什么？
4. 全文是否可合法获取、能否冻结并形成唯一文本锚点？
5. 参考文献列表是否完整，是否存在来源或去重异常？
6. 哪些陈述必须回溯原始论文后才能进入金标？
7. 是否存在物种、细胞类型、剂量、时间、研究设计或效应方向混写风险？

必须写入独立的人工审计记录。
