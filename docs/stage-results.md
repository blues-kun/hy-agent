# 小模型训练 · 阶段记录

项目采用“SFT → 专家反馈 → 强化学习”的工具策略训练路线。PPO / GRPO 纳入方法比较，当前数值展示聚焦以 RP-GRPO 为核心策略的阶段实验；核验 SFT 仍作为独立任务管理。

## 约 100 步：RP-GRPO 与普通 GRPO

下表按项目负责人本次提供的阶段汇总原值记录，不是本次文档更新重新运行训练得到的结果。

| 指标 | RP-GRPO | 普通 GRPO |
| :--- | ---: | ---: |
| 平均成功率 | 91.25% | 85.00% |
| 配对成功率 | 82.50% | 76.25% |
| 数值任务成功次数 | 13/16 | 7/16 |
| 文字任务成功次数 | 60/64 | 61/64 |

按两类成功次数加总，RP-GRPO 为 73/80、普通 GRPO 为 68/80，与所给平均成功率一致。平均与配对指标分别提高 6.25 个百分点；数值任务增加 6 次成功，文字任务减少 1 次。此处 80 是所给汇总的计数分母，不额外推断为 80 个独立问题族。

当前未随汇总提供精确 checkpoint、数据分区、随机种子、重复次数、逐条输出、配对指标的统计定义和分母。配对成功率按原值展示，不反推出整数配对次数，也不据此给出显著性或最终泛化结论。当前也没有可附表的 PPO 数值结果。

## 持续训练

继续训练时保留同一 SFT 起点、工具与奖励版本，补充更长训练曲线、多随机种子和独立任务结果。普通 GRPO、RP-GRPO 与 PPO 对照分别记录；PPO 的实验产物后续补充，不将现有 PPO 式裁剪实现等同于完整 PPO 基线。

最终发布将阶段表绑定到代码提交、数据版本、适配器哈希、预算与逐条评测记录；权重仍单独分发，参见[权重说明](../mito/rp_grpo/checkpoints/README.md)。
