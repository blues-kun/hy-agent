# RotatE · 从图谱预测到机制发现

MITO Agent 将图谱关系预测用作机制探索的候选入口：模型提出可能被遗漏的联系，文献与实验决定哪些解释值得保留。

## 闭环设计

语言模型 SFT / RL 与 RotatE 图谱表示学习分别进行；两条路线在应用层通过证据、条件与任务上下文衔接。候选由 Hy3 结合领域小模型复核，组织为可区分不同解释的机制假设，再由研究者确认并开展湿实验。

![RotatE 机制推理与湿实验反馈闭环](../assets/mito-mechanism-loop.svg)

| 环节 | 处理内容 | 输出 |
| :--- | :--- | :--- |
| 图谱整理 | 对齐实体、关系方向、来源与实验条件，筛选可用三元组 | 图谱表示训练子集 |
| RotatE 映射 | 在复数向量空间表示实体，将关系建模为头实体到尾实体的旋转 | 候选关系分数与同组排名 |
| 候选复核 | 合并别名，检查已有文献、条件适用、反向证据和缺失环节 | 可检验的机制假设 |
| 规划与验证 | 设计对照、干预及可区分不同解释的实验，由研究者确认执行 | 实验观察与候选状态更新 |
| 证据回流 | 将支持、反驳或未决结果绑定来源、实验条件和版本，经复核后更新记录 | 更新图谱证据及候选状态，驱动下一轮预测 |

闭环回流保留支持与反向证据，也允许结果未决；未验证候选保持独立，不能因模型分数高而自动升级为事实。当前已完成候选导出，并展示知识网络、机制焦点、实验观察记录及方案草稿。候选与匹配湿实验的逐项验证、图谱自动回流仍按此接入设计推进。

RotatE 的关系旋转用于知识图谱链接预测，不是因果发现证明。算法依据：[Sun et al., RotatE, ICLR 2019](https://arxiv.org/abs/1902.10197)；[作者实现](https://github.com/DeepGraphLearning/KnowledgeGraphEmbedding)。本仓库展示该应用策略，未将 RotatE 训练实现混入工具策略 RL 代码。

## 当前图谱与候选

以下统计来自项目提供的 `rotateE_knowledge_relation.md`，候选清单与原图谱分别管理。

| 对象 | 数量 | 含义 |
| :--- | ---: | :--- |
| 原知识图谱不同关系 | 2,234 | 对应 2,312 条来源记录、2,414 个实体 |
| 本次表示训练子集 | 379 | 从原图谱严格筛选的关系子集 |
| 查询组合 | 245 | “源实体＋关系”组合 |
| 有可保留输出的组合 | 244 | 每组导出 Top-3 |
| 模型候选关系 | 732 | 涉及 330 个实体、28 种关系类型 |

732 = 244 × 3，是候选导出数量，不是已验证的新机制数量。候选包含调控、方法、定位等多类关系；同组排名不等于可跨组比较的可信概率。候选保持独立，尚未自动写入原始证据图谱。

## 从候选关联到机制问题

工作台以研究对象为中心，将文献关系、RotatE 模型候选和人工假设分层展示。核验小模型提供证据支持与条件约束，Hy3 据此组织机制解释、竞争假设和待补证据；实验规划模块再生成待研究者确认的方案。

| 模型输出的候选连接 | 后续推理与验证问题 |
| :--- | :--- |
| mitochondria → promotes → FoxO1 与自噬基因启动子的结合 | 哪些细胞与干预条件下有证据支持？能否区分直接作用与中间过程？ |
| ACO2 → upregulates → ATP | 变化是否依赖 ACO2 活性与代谢背景？应补充哪些对照和测量？ |
| mitochondrial fission/fusion → regulates → insulin secretion | 形态变化与分泌变化是否存在可重复联系？如何排查共同上游因素？ |

这些是从项目候选清单形成的研究问题，不是已确认的生物学结论。图谱缺失连接也不等于文献中从未报道。

## 本轮质量与机制使用

项目材料记录的本轮 MRR 为 **0.0291**，低于频率基线 **0.2099**。因此当前交付用于追溯、筛选和改进候选生成，尚不能说明该预测已优于简单基线；是否进入湿实验由证据复核与研究者判断。

例如 `ACO2 → upregulates → ATP`、`MCU → mediates → 葡萄糖刺激的胰岛素分泌` 可作为检索与验证线索，不直接写成已确认机制。当前 OPP／蛋白合成卡片是人工提出的假设，**不是本轮 RotatE 预测发现**；不能将其湿实验图像用作该预测算法的验证成绩。

下一阶段优先处理实体别名、关系类型与来源分区，比较候选排名质量，再将通过复核的假设接入实验规划和反馈流程。
